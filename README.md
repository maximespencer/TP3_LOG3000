# Calculatrice Flask — LOG3000 TP3

**Équipe :** <NUMÉRO D'ÉQUIPE>

## Objectif

Application web de calculatrice simple construite avec Flask (Python). L'utilisateur
saisit une expression binaire (ex. `7*8`) à l'aide de boutons et le serveur renvoie le résultat.

## Prérequis

- Python 3.10+
- pip
- Git

## Installation

```bash
git clone <URL_DU_DEPOT>
cd TP3---LOG3000
pip install -r requirements.txt
python app.py
```

Puis ouvrir <http://127.0.0.1:5000> dans un navigateur.
